# 저장된 표 프레임과 쪽 번호의 원문 소유권

두 패치는 rhwp 0.8.7의 기존 r13 뒤에 순서대로 적용하는 **r14의 공통 조판 코어 변경**입니다. Pwh 0.6.41과 Desktop 0.1.22에 함께 적용합니다. 적용 대상은 Pwh와 Pwh Desktop이 공유하는 WASM이며 네이티브 CLI나 rhwp 원본 배포본의 변경을 뜻하지 않습니다.

`rhwp-0.8.7-stored-parallel-frame-minimum.patch`는 빈 저장 호스트에 함께 놓인 표의 바깥 여백과 선언된 물리 프레임을 구분합니다. 반복 제목행 뒤에서 나란한 셀이 같은 저장 행 최소 높이를 공유하고, 원문의 쪽 원점과 프레임 수가 그 관계를 확인할 때 실제 승인된 조각 상자에 그 공간을 보존합니다. 앞 조각들이 사용한 몸통 높이를 기록하여 마지막 조각은 남은 최소 공간을 사용합니다. 내용 컷은 공간 예약과 별도로 유지합니다.

이 해석은 열 소유 범위가 비거나 겹치는 경우, 교차 행 병합, 서로 다른 선언 최소 높이, 가운데 맞춤, 편집되거나 합성된 줄 배치에는 적용하지 않습니다. 음수 좌표, 양수 위치로의 단순 되감김, 짧은 문단의 로컬 원점 재시작은 물리 쪽 경계로 인정하지 않습니다. 선언 프레임이나 실제 내용이 가용 본문을 넘으면 억지로 축소하지 않습니다.

쪽 나눔에서 승인한 `source_parallel_frame`을 페이지 항목에 명시적으로 기록하고 그리기와 커서 계산에 전달합니다. 모양이 비슷하거나 높이 재지정 값이 있다는 이유만으로 기존 줄 간격 접기 동작을 끄지 않습니다.

`rhwp-0.8.7-page-number-source-activation.patch`는 쪽 번호 위치 설정이 원문의 컨트롤 순서와 실제 표 조각을 기준으로 시작하도록 합니다. 같은 빈 호스트의 표 사이에 설정이 있으면 앞 표의 마지막 소유 조각을 확인합니다. 아직 설정이 없는 앞쪽과 이후의 이어받기 조각을 구분하며, 이전 구역에서 이어온 형식도 자기 구역의 설정이 시작되기 전까지만 유지합니다. 번호 재시작·감추기·일반 본문 글줄의 기존 판정은 유지합니다.

원문의 글자, 글꼴, 문서 여백, 저장된 셀 높이를 바꾸지 않습니다. 승인된 상자만 그리며 문서 내용을 잘라 가리는 보정이나 전역 줄 재배치는 사용하지 않습니다.

소스 단위 시험은 `parallel-row-source-frame.mjs`의 19건과 `page-number-source-activation.mjs`의 22건으로 분리합니다. 실제 인쇄 품질은 같은 물리 쪽·척도에서 PDF를 대조하고, 문자 누락·중복과 기하 검사를 별도로 진행해야 합니다. 소스 시험이 실제 화면이나 모든 문서의 완전 일치를 보장하지 않습니다. 고정된 빌드 입력과 단계별 소스 해시는 `scripts/build-patched-core.mjs`에 기록합니다.
