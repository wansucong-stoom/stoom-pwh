# 중첩 표의 다음 쪽 원문과 온전한 셀 배치

`rhwp-0.8.7-stored-nested-tail-owner.patch`는 r14의 열여덟 번째 패치입니다. Pwh 0.6.41·Desktop 0.1.22에 함께 적용하며, Pwh와 Pwh Desktop이 공유하는 조판 코어에 적용합니다. Studio 메뉴나 Desktop 화면에서 좌표를 덧붙이는 변경이 아닙니다.

## 보완한 공통 규칙

빈 호스트의 원본 줄, 다음 문단의 좌표 재시작, 자식 표의 현재 측정값과 바깥 여백이 정확히 닫는 프레임만 다음 쪽 경계로 인정합니다. 원본의 첫 물리 프레임 높이를 보존하되, 그 빈 공간을 채우려고 다음 행의 원문을 미리 소비하지 않습니다.

- **소비 경계:** 같은 원본 판정을 일반 행 스캐너, 행 전체 수용 최적화, 상위 표에 투영한 자식별 `RowCut`이 공유합니다. 현재 커서 뒤에 검증된 경계가 남아 있으면 행 전체 수용으로 건너뛰지 않습니다. 커서 자체가 그 경계라면 정상적으로 내용을 소비해 빈 쪽을 만들지 않습니다.
- **안정된 본문 기준:** 저장 원본의 적격 여부는 문서·구역·표의 안정된 입력으로 계산합니다. 마지막으로 그린 쪽의 남은 영역이나 호출 순서에 의존하지 않습니다. 용지 변경과 정규화 사본의 주소 변경도 캐시의 본문 기준에 반영합니다.
- **온전한 행:** 행 내부를 자르지 않은 원본 조각은 전체 표와 같은 행 높이·안 여백·중첩 위치 기준을 사용합니다. 원본 프레임의 추가 빈 공간과 문단의 실제 내용 기준점을 분리해, 이미 배치된 그림을 글줄 전진 뒤로 밀거나 빈 공간의 중앙으로 옮기지 않습니다.
- **비가시 설정:** 셀 안의 한 단 설정은 보존하는 배치 정보입니다. 글과 그림이 같은 온전한 셀에 있어도 이 설정 때문에 별도 내용 소유자가 생긴 것으로 판단하지 않습니다. 다단 설정이나 다른 미지원 개체까지 확장하지 않습니다.
- **그림 편집:** 중첩 깊이와 관계없이 그림의 실제 공간 속성이 바뀌면 해당 호스트의 원본 배치 캐시를 무효화합니다. 재조합한 측정 템플릿을 원본 파티션으로 저장하지 않아, 재열기에서 옛 분할 근거가 되살아나지 않게 합니다. 문서 전체를 편집 상태로 바꾸지 않으며 실행 취소는 이전 원본 상태를 복원합니다.

## 조건과 제외 범위

원본 저장 줄과 현재 측정 높이·본문 영역이 모두 확인되어야 합니다. 명시적 쪽·구역·단 나눔, 원본 줄이 없는 재조판, 닫힘 값 불일치, 이동된 자식, 반복 제목행, 경계를 가로지르는 병합 셀은 이 규칙으로 추정하지 않습니다. 소스 판정 중 기존 측정 옵션을 바꾸더라도 호출자의 값을 복원합니다.

변경 지점은 rhwp 기반 코어의 소비·측정·전체/부분 표 배치 및 그림 속성 명령입니다. 이것은 모든 관찰 증상이 수정 전 upstream에서도 같은 형태였다는 주장이 아닙니다. 앞선 float 표시 순서 회귀는 Pwh r13 패치에서 발생했으며, 각각의 실제 검증 범위를 따로 기록합니다.

## 검증 범위

공개 자료는 익명 합성 HWPX와 1×1 PNG 생성 코드뿐입니다. 사용자 원문·이미지·경로는 포함하지 않습니다. `stored-nested-tail.test.mjs`는 두 소비 경로의 실제 분할, 원문 한 번씩 표시, 역순 렌더링, 용지 변경·새 문서 비교, 그림 변경·저장·재열기·실행 취소 및 독립 일반 재조판 코어와의 반례를 확인합니다. 원본 소스에서 추출한 Rust 함수 시험 87건은 별도로 실행합니다.

배포 r14의 실제 JS·WASM·소스와 독립 기준 r13을 지정해 검증합니다. 후보 전용 플래그는 제거했으며 CI에서 해시가 고정된 원본 소스와 기준 코어를 준비해 검사합니다. `scripts/prepare-core-regressions.mjs`는 원본 ZIP에 같은 열여덟 패치를 적용하며 설치된 앱을 변경하지 않습니다. 건너뛴 검사는 검증 성공으로 계산하지 않습니다.

같은 원본의 새 전체 PDF와 앞쪽 순차 판정은 [조판 일치 검증](../LAYOUT-FIDELITY.md#r14-source-frame-candidate)에 기록합니다. 그림 속성 시험의 재열기 검증은 원문과 쪽 소유 범위에 관한 것이며, 모든 편집 경로에서 저장 전후 PDF 픽셀이 같다는 뜻은 아닙니다. 전체 문서의 품질 승인과 설치판·운영 승격도 별도 단계입니다.
