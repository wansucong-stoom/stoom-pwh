# 중첩 개체와 떠 있는 표의 원본 프레임

이 문서는 r14의 세 번째 추가 코어 패치가 사용하는 일반 규칙을 설명합니다. Pwh 0.6.41과 Pwh Desktop 0.1.22가 공유하는 rhwp 기반 코어 변경입니다. 문서 이름·기관명·쪽 번호·특정 셀 좌표를 기준으로 분기하지 않습니다.

## 앵커와 표시 순서

컨트롤의 텍스트 위치는 연결할 줄을 뜻합니다. 양의 문단 기준 오프셋으로 가시 줄 아래에 놓이는 float를 무조건 글 앞 흐름 요소로 바꾸면 호스트 제목이 표 아래에 놓일 수 있습니다. Pwh r13의 혼합 문단 투영에서 생긴 이 회귀를 원본 프레임으로 구분합니다.

다음 조건을 모두 확인한 한 줄 호스트에만 닫힌 프레임을 인정합니다.

- 실제 저장 줄과 현재 폭에서 조합한 가시 줄이 각각 하나이며 높이·폭·시작·줄 간격이 일치합니다. 표 위끝은 가시 줄 상자를 침범하지 않습니다.
- 문단 기준 위쪽 정렬·위아래 어울림인 단일 float이며, 다음 원본 문단의 첫 줄이 `호스트 원점 + 오프셋 + 위 바깥 여백 + 표 몸통 + 아래 바깥 여백`을 닫습니다.
- 이 전체 원본 끝점이 실제 물리 본문 영역에 들어갑니다. 작은 용지에 남아 있는 오래된 저장 좌표를 새 배치의 증거로 사용하지 않습니다. 모르는 본문 크기를 A4 등의 상수로 추정하지 않습니다.
- 원문 분할·서식·하위 내용이 수정되거나 합성되지 않았고, 현재 재조판을 나타내는 공간 측정값도 없습니다. 측정한 몸통 높이가 원본 높이와 일치해야 합니다.

승인한 하나의 프레임을 측정과 일반·부분 셀 그리기가 같이 사용합니다. 호스트는 표 위끝까지, 표는 몸통과 아래 바깥 여백까지 공간을 소유합니다. 사용하지 않은 말미 줄 간격은 겹칠 수 있지만 가시 글줄은 겹치지 않습니다. 같은 오프셋·여백·빈 공간을 두 번 더하지 않습니다. 현재 소스 형태가 맞지 않는 경우는 비용이 큰 자식 행 높이 계산에 들어가기 전에 배제합니다. 실행 시간 향상 수치는 별도로 측정하지 않았습니다.

## r16 보완: 작은 용지의 기존 분할 경로

준비 중인 r16의 20번 [`authenticated-float-projection`](rhwp-0.8.7-authenticated-float-projection.patch)는 위 규칙의 소비 조건을 일치시킵니다. 원인은 **Pwh가 r14에 추가한 17번 코어 패치**입니다. 행 투영을 배제할 때는 저장 원점·다음 문단의 외형만 검사하고, 실제 예약·그리기에서는 위의 전체 프레임 조건을 확인했습니다. 작은 본문 영역에서 앞 조건만 통과하면 기존 분할을 막아 둔 채 새 프레임도 사용하지 못해 표시 중복·누락·음수 좌표가 발생했습니다.

행 투영을 배제하는 지점도 `closed_stored_nested_float_frame`의 전체 원문·측정·본문 영역 검증을 사용하도록 통일했습니다. 검증이 실패하면 기존 분할을 그대로 유지합니다. 원문 좌표·용지 크기·허용 오차를 바꾸거나 문서별 예외를 추가하지 않습니다.

독립 r13과 비교한 작은 용지 3개는 기존 기대값을 유지해 통과했고, 전체 프레임이 들어가는 경계 앞뒤를 포함한 합성 용지 9종에서 원문 단일 표시·페이지 경계·역순 렌더·저장·재열기를 검사했습니다. 제외 경로는 r13, 유효한 프레임 경로는 수정 전 코어와 각각 전체 출력을 비교했습니다. 기존 소스 함수 시험 33개에 소비 조건 반례 5개를 더했습니다.

앞선 CI에서는 선택적 기준 코어 환경변수가 설정되지 않아 작은 용지 비교 3개가 건너뛰어졌습니다. 준비 스크립트와 실행기가 `PWH_REFERENCE_CORE_JS/WASM`의 독립 r13을 `PWH_FLOAT_FRAME_BASE_JS/WASM`에도 연결하고, 설정된 필수 입력이 없으면 검사 누락을 보고하도록 보완했습니다. 기본 실행에서 환경별 시험을 건너뛰는 것과, 기준 코어를 준비한 배포 검증에서 빠지는 것은 구분합니다. 이 기록은 후보의 회귀 보완이며 최종 누적 공식 빌드·배포 완료는 아닙니다.

## 자식 개체의 첫 물리 조각

원본 인라인 개체 줄과 실제 자식 커서가 입증한 첫 프레임은 내용 줄의 합과 다를 수 있습니다. 같은 원본 소유권으로 선언 물리 높이와 자기 위·아래 바깥 여백을 한 번씩 보존합니다. 겉 셀 여백을 늘리거나 빈 높이를 미래 내용 행에 나누어 넣지 않습니다. 실제 자식 커서가 없는 혼합 조각까지 적용하지 않습니다.

뒤 형제 표가 새 빈 쪽에서 시작하면 이전 형제가 이미 소비한 문단 오프셋을 다시 더하지 않습니다. 첫 표, 이미 내용이 있는 쪽, 이어지는 표 조각은 기존의 서로 다른 오프셋 규칙을 유지합니다. 측정 예산과 그리기가 같은 판정 함수를 호출합니다.

## 편집·제외 범위와 시험

편집 후 재조판은 원본 줄 태그를 보존할 수 있으므로 태그와 `dirty` 여부만으로 원본임을 증명하지 않습니다. 현재 공간 측정값이 생긴 소유자는 기존 일반 재조판으로 돌아갑니다. 실행 취소는 원문과 승인된 원본 프레임을 함께 복원해야 합니다. 이 검사는 편집 명령 자체의 구현을 바꾸지 않습니다.

캡션·여러 가시 줄·여러 컨트롤·다른 기준점·겹침·현재 폭에서 달라진 줄·맞지 않는 몸통 높이·불분명한 원본 커서와 몸체보다 큰 저장 프레임은 각각 기존 경로를 유지합니다. 그 경로의 모든 중간 조각 문제가 해결됐다는 뜻은 아닙니다. 큰 float의 기존 중복·누락 사례는 별도 개선 대상으로 남아 있습니다.

`tests/engine-source-ownership/closed-float-source-frame.mjs`, `sibling-table-offset.mjs`와 중첩 개체 프레임 시험은 실제 생산 함수의 원본 코드를 추출합니다. 합성 HWPX는 줄 간격·용지 크기·여백·원문 주소·편집·실행 취소·실제 SVG 클립을 검사하며 기관 문서를 포함하지 않습니다. 소스 시험과 합성 시험을 실제 PDF의 쪽별 내용·기하 감사와 구분합니다. [고정 승인 기준과 결과](../LAYOUT-FIDELITY.md#r14-source-frame-candidate)를 참고하세요.

r14의 Node·브라우저 시험은 후보 전용 플래그 없이 배포 코어 CI에서 실행합니다. 소스 조건과 독립 일반 재조판 비교는 `scripts/prepare-core-regressions.mjs`가 해시로 고정한 원본 소스·r13 기준 코어를 준비하며, 원본에 같은 열여덟 패치를 적용합니다. 환경별로 제외한 검사는 통과 수에 포함하지 않습니다.
