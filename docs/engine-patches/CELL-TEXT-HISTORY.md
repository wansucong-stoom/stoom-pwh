# 셀 텍스트 실행 취소와 원래 조판 상태

rhwp Studio에서 유래한 공통 편집기는 일반 셀 입력을 Undo할 때 삽입한 글자를 다시 삭제했습니다. 이 방법으로 글은 돌아오지만, rhwp 코어가 셀을 재조판하면서 바꾼 줄 배치와 원본 프레임 사용 여부는 돌아오지 않습니다. 저장된 줄 정보에 기대는 Pwh의 중첩 표 경로에서 차이가 커질 수 있습니다. Desktop 호스트의 창·입력 브리지에서 생긴 문제는 아닙니다.

r17의 합성 중첩 표에서 글자 하나를 입력하고 반대로 삭제하면 본문 텍스트는 같은데 2쪽이 3쪽으로 늘어났습니다. 별도 비공개 시험 사본에서는 39쪽 수는 같았으나 6쪽과 17~23쪽의 출력 SVG와 텍스트 배치가 달라졌습니다. 예전 검사는 조판을 먼저 끝낸 경로와 나중에 끝낸 경로를 비교했으므로 두 결과가 똑같이 틀리는 경우를 검출하지 못했습니다.

27번 [코어 패치](rhwp-0.8.7-scoped-cell-text-history.patch)는 편집할 셀의 전체 구조 경로, 대상 문단과 같은 셀에서 영향을 받는 뒤 문단의 줄 좌표, 구역의 저장 정보와 원본 프레임 사용 이력을 기록합니다. 실행 취소는 그 상태를 복원한 뒤 파생 렌더링만 다시 계산합니다. 입력 때 문서 전체나 바깥 표 전체를 복사하지 않습니다. 이 기록은 같은 편집기의 순서대로 실행 취소하는 경우를 위한 것이며, 셀 문단 수가 달라져 있으면 먼저 구조 변경을 되돌려야 합니다.

[공통 편집기 패치](../../scripts/patch-cell-text-history.mjs)는 셀의 문자 삽입·삭제·덮어쓰기와 IME 조합의 첫 수정에 이 기록을 사용합니다. 연속 입력이나 삭제를 하나로 묶으면 처음 상태만 보존하고 중간 기록은 해제합니다. 중첩 셀이 서로 다른 경우에는 끝 셀 번호가 같아도 이력을 합치지 않습니다. 조판이 대기 중인 일반 셀 입력을 되돌릴 때에는 중간 결과 대신 복원된 상태를 한 번 조판합니다.

검증의 기준은 **편집 전과 실행 취소 후**입니다. [코어 회귀 시험](../../tests/cell-text-layout-history.test.mjs)은 페이지 수, 출력 SVG, 글자 좌표, 저장 XML과 조판 이력, 재열기와 Redo를 비교합니다. [브라우저 입력 시험](../../tests/desktop-cell-layout-history-browser.test.mjs)은 실제 브라우저 키와 조합 이벤트로 타이핑과 실행 취소를 확인합니다. 이 검사는 한컴 PDF와의 페이지별 일치율 검사와 별개입니다.

| 검증 항목 | r17 | r18 |
| --- | --- | --- |
| 합성 중첩 표의 편집 → Undo | 2쪽에서 3쪽으로 변경 | 편집 전 2쪽 및 저장 상태 복원 |
| 39쪽 표 문서 사본의 편집 → Undo | 8개 쪽 배치 변경 | 39쪽의 출력 SVG·글자 좌표·저장 XML 복원 |
| 격리 Electron에서 중첩 셀 클릭·입력·Ctrl+Z | 기존 시험에서 8개 쪽 SVG 변경 | 실제 키 입력 후 39쪽 SVG 복원, DOM 입력 포커스·커서 확인 |

별도 HWP/HWPX 사본 3개, 총 71쪽에서 이전 버전과 같은 최초 출력과 저장 후 재열기 출력을 확인했습니다. 한글 조합은 Chromium 개발자 도구 프로토콜로 입력과 취소를 검증했으며 Windows 입력기 직접 시험과는 구분합니다.

독립적으로 다시 빌드한 코어 4개 파일은 시험에 사용한 파일과 바이트가 같았습니다. [검증 기록](../verification/cell-history-0.6.45.json)에는 코어 476건, 브라우저 포함 시험 526건 통과와 산출물 해시를 기록했습니다. 브라우저 포함 집계에는 Windows에서 시험 프로그램 실행을 시작하지 못해 별도로 재실행해 통과한 두 Rust 시험이 포함됩니다.

39쪽 사본의 같은 중첩 셀에서 캡처와 즉시 해제만 200회씩 비교한 결과, 전체 바깥 문단 조각의 95번째 백분위는 약 0.59ms, 셀 문단 조각은 약 0.013ms였습니다. 이는 기록 비용 비교입니다. 깊은 셀의 편집과 실행 취소는 각 약 1초가 걸렸으며, 중첩 경로의 동기 페이지 나눔은 남아 있습니다.
