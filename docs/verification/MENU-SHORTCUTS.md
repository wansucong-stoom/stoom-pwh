# 메뉴와 겹글쇠 검증

적용 버전: **Pwh 0.6.59 · Desktop 0.1.40**. 공통·Desktop 소스와 패키지에 함께 적용합니다. GitHub 공개와 Microsoft Store 제출·심사·게시 상태는 구분하며, Store 설치판에는 게시 이후 반영됩니다.

## 원인과 적용 계층

발생 계층은 **rhwp Studio에서 유래한 Pwh 공통 편집기**입니다. 공통과 Desktop 번들에 같은 수정을 적용하며, rhwp 원천 WASM 코어 r29와 문서 조판 계산은 변경하지 않습니다.

- 메뉴는 마우스로 열 때 문서 textarea의 초점을 유지합니다. 기존 문서 단계의 키 처리가 메뉴의 버블 단계보다 먼저 실행돼 Esc가 F5 셀 블록을 해제하고 Delete가 선택한 본문을 지웠습니다. 합성 문서의 신뢰된 실제 키 입력에서 두 문제를 확인하고 실행 취소로 복원했습니다.
- 겹글쇠 대기 상태는 N/Q와 K/M/G/V에 흩어져 있었고, IME의 Process 이벤트와 물리 키 처리·한글 자모 대응이 일관되지 않았습니다. Ctrl을 누른 채 N,N을 입력하면 두 번째 N이 새 시작으로 해석될 수 있었습니다.
- Desktop 호스트는 Alt+V를 다른 이름으로 저장에 사용하지만 투명 선 메뉴에도 Alt+V,T가 표시됐습니다. Desktop 파일 키는 유지하고 투명 선의 공통 표시를 Ctrl+G,B로 정리했습니다.

## 수정과 사전·사후 확인

| 항목 | 확인 방법 | 사후 기준 |
| --- | --- | --- |
| 메뉴의 Esc | F5 셀 블록 → 보기 목록 → Esc | 목록만 닫히고 셀 선택 단계 유지 |
| 메뉴의 Delete·Enter | 본문 일부 선택 → 편집 목록 → Delete·Enter → Esc | 본문·기존 선택·입력 초점 보존 |
| 선택 복원 확인 | 메뉴 취소 후 Delete → 실행 취소 | 원래 선택한 글자만 삭제하고 원문 복원 |
| 메뉴 실행 | 방향키로 활성 항목 선택 → Enter, 표 목록의 S, 목록을 닫은 뒤 셀 블록 P | 각 클릭 명령 한 번 실행, 해당 대화상자 하나 표시 |
| 본문 겹글쇠 | Ctrl+G,T/C/B/P, Ctrl+K,H/B | 보기 명령 한 번 실행, 실제 하이퍼링크·책갈피 창 표시 |
| 같은 시작·끝 글쇠 | Ctrl을 누른 채 N,N → 실행 취소 | 각주 하나 삽입, 원래 제어 구조 복원 |
| 셀 겹글쇠 | F5 → Ctrl+G,C / Ctrl+M,R → 실행 취소 | 보기 전환 중 셀 선택 유지, 글자 색과 원문 복원 |
| 초점·다른 단축키 | Ctrl+G 뒤 초점 이동, Ctrl+Shift+C | 남은 일반 글쇠 입력 허용, 가운데 정렬을 이전 겹글쇠로 오인하지 않음 |
| IME 이벤트 모형 | Process·229·KeyG/KeyT와 한글 자모 대응 | 명령의 동일한 물리 키 해석 |

메뉴·본문·셀 입력은 시험 사본의 실제 신뢰된 키 이벤트로 확인합니다. IME Process 이벤트의 별도 주입 시험은 **합성 이벤트**이며, 실제 Windows 한글 IME 전체 조합·확정 시험을 대체하지 않습니다.

- [겹글쇠 단위 회귀](../../tests/editor-chord-routing.test.mjs)와 기존 표 만들기 검사: 10건 통과. 모듈 단독 사전 시험에서는 6건 실패를 확인했으며, 이 수치를 기존 앱 전체의 단축키 실패율로 해석하지 않습니다.
- [Desktop 메뉴 회귀](../../tests/desktop-hancom-menu-browser.test.mjs)에 열린 메뉴의 Delete 차단, 닫은 뒤 원래 선택 삭제와 실행 취소 검사를 추가합니다. 이 브라우저 자동 시험은 별도 실행 조건이 필요하며, 실행을 생략한 경우 통과 수에 포함하지 않습니다.
- 두 독립 디렉터리에서 공통·Desktop 편집기를 각각 다시 빌드해 여섯 배포 파일의 바이트 일치를 확인합니다. 엄격한 TypeScript 검사는 Studio 306개 소스와 Pwh 연결 16개를 검사합니다. 번들과 manifest·입력 해시는 함께 생성합니다.
- 최종 소스의 전체 Node 시험은 675건 중 **289건 통과·실패 0건·386건 생략**입니다. 별도 브라우저·코어 실행 조건이 필요한 시험은 생략 수에 포함됩니다. 정적 검사는 401개 파일에서 오류·경고 0건이며, 두 번들의 입력 기록·해시 검사도 통과했습니다.

## 남은 범위

기존 실행 취소는 기록 복원 뒤 파생된 셀 선택을 해제하는 정책입니다. 색과 본문은 복원하지만 셀 블록까지 복원한다고 주장하지 않습니다. 그림 배치·조판·쪽 수·프린터 출력이나 모든 한글 단축키의 동등성을 이번 메뉴 검증으로 판단하지 않습니다. WASM과 조판 계산을 유지했으며 245쪽 PDF를 새로 비교한 결과도 아닙니다.
