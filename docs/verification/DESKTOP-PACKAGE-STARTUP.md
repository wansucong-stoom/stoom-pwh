# Desktop 패키지 시작 검증

수정 계층은 Desktop 패키징입니다. Windows Desktop 0.1.45는 공통 인증 저장소가 정적으로 참조하는 Linux 자격 증명 어댑터를 패키지에서 누락했습니다. Node는 운영체제 분기를 실행하기 전에 정적 모듈 참조를 해석하므로 Windows에서도 문서 탭 시작이 실패했습니다. Codex 플러그인 캐시가 설치된 Desktop 파일을 덮어써서 발생한 문제가 아닙니다.

Pwh 0.6.67 · Desktop 0.1.48부터 다음 조건을 적용합니다.

- Windows MSIX·MSI·오프라인 ZIP과 Linux는 같은 실행 자산 수집 규칙을 사용합니다. 빌드 도구와 생성되는 배포 정보는 구분하고, 실행 모듈·화면·정적 자산과 운영체제 어댑터를 함께 수집합니다.
- 완성 패키지에 포함된 Node로 Desktop 모듈을 불러옵니다. 소스 트리에서 실행한 결과로 대체하지 않습니다.
- 완성 패키지의 문서 탭 프로세스를 두 번 시작합니다. 첫 번째는 새 문서, 두 번째는 그 HWPX를 기존 파일로 다시 여는 경로입니다. 초기화 응답과 파일 준비를 확인하고 입력 바이트가 유지되는지 검사합니다.
- 임시 앱 데이터만 사용하고 실제 사용자 설정·계정·문서를 읽거나 변경하지 않습니다. AI 로그인·외부 서버 호출·화면 조작을 요구하지 않습니다.
- 모듈을 고의로 누락한 시험에서 시작 검사가 실패해야 합니다. 새 어댑터가 공통 수집기에 자동으로 포함되는지도 확인합니다.
- Store 제출 검증은 최종 MSIX를 풀어 실행 자산 전체를 원본 소스와 대조하고 문서 탭 시작을 다시 검사합니다. 패키지 생성 전 검사와 제출 직전 검사를 별도로 유지합니다.

이 검사는 설치 파일의 시작·의존성·문서 초기화 경로를 확인합니다. 모든 쪽의 시각적 조판·입력·인쇄·AI 계정 연동 검증을 대신하지 않습니다. 공통 코어 r32와 기존 편집·성능 개선은 변경하지 않습니다.
