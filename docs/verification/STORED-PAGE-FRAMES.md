# 저장 쪽 프레임의 공통 코어 검증

발생 계층은 **rhwp 기반 공통 코어**입니다. 기존 98개 패치를 보존한 뒤 99번 `stored-physical-page-frame`과 100번 `shared-stored-frame-plan` 패치를 적용합니다. 고정 원본은 rhwp 0.8.7의 `1a76570e833917d15817415a53c09ad61ab3203f`이며, 이 수정은 Pwh가 유지하는 패치입니다.

## 공통 적용 조건

누락된 글줄을 합성해 연속 좌표를 만들기 전에, 원본이 기록한 쪽 프레임을 확인합니다. 자리차지 표의 본체·바깥 여백과 후속 글줄이 같은 끝점을 기록하고 그 전체가 앞쪽의 실제 잔여를 넘으면, 표 앞의 제목·안내 줄도 포함한 원래 쪽 시작을 유지합니다. 빈 앵커 줄 하나가 잔여에 들어간다는 이유로 전체 표의 쪽 경계를 없애지 않습니다.

문단 기준 자리차지 그림은 그림·바깥 여백·아래 캡션 전체와 후속 본문의 재시작 높이가 같을 때 다음 쪽을 소유할 수 있습니다. 호스트의 앞쪽 글줄과 그림의 예약을 분리하고, 같은 계획을 높이 보완·쪽 분할·실제 그리기에 사용합니다. 번호·필드가 들어 있는 캡션도 일반 텍스트로 구성합니다.

원본 좌표의 단순 감소만으로 경계를 만들지 않습니다. 겹침·용지 기준 개체, 닫히지 않는 후속 원점, 변경된 문단·셀 내부의 재조판 이력은 이 저장 프레임의 근거로 쓰지 않습니다. 원문·글꼴·용지·표 크기는 배치 비교를 위해 수정하지 않습니다.

## 검증 방법

- `tests/page-frame-ownership.test.mjs`: 본문 첫 줄 가운데 정렬, 밑줄 공백, 표의 직접 시작·앞 제목, 캡션 유무별 그림 이월, 제외 사례를 실제 WASM으로 검사합니다. 저장·재열기와 스냅샷 실행 취소를 포함합니다.
- `prepare-core-regressions.mjs`는 99번 이전의 고정 r31 코어를 별도 제외 사례 기준으로 준비해 `PWH_PAGE_FRAME_REFERENCE_JS`와 `PWH_PAGE_FRAME_REFERENCE_WASM`으로 전달합니다. 기존 중첩 표의 독립 재조판 기준 r13은 별도로 유지합니다.
- 전체 공통 코어 회귀 검사와 기존 문서의 쪽 수·텍스트 배치·인쇄 SVG를 대조합니다. 합성 자료와 실제 문서의 비교 범위를 구분합니다.
- 한글 기준 PDF와 새 후보에서 전체 출력한 PDF를 같은 쪽·원점·물리 크기에서 150dpi로 비교합니다. 일반 잉크 F1 0.95, 진한 잉크 F1 0.90과 2픽셀 허용 기준을 유지합니다. 쪽 수가 같아졌다는 결과만으로 조판 일치 완료를 선언하지 않습니다.
- 원본·출력·실행 코어의 해시, 내용 누락·중복·다른 쪽 배정과 용지 넘침을 별도로 기록합니다. 사용자 문서·기준 PDF·비교 이미지는 공개 저장소에 포함하지 않습니다.
