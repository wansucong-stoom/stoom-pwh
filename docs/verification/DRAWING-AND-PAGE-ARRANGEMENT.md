# 도형 도구와 자동 쪽 배치 검증

상태: **개발판**. 현재 정식 배포는 Pwh 0.6.62 / Desktop 0.1.43 / 공통 코어 r31입니다. 이 문서의 변경은 98번 코어 패치와 공통·Desktop 편집기 후보에 적용하며, 정식 런타임 잠금·설치판·Store는 아직 갱신하지 않았습니다.

## 변경과 원인

| 계층 | 확인한 문제 | 변경 |
| --- | --- | --- |
| rhwp Studio 유래 입력 | 연결선이 개체 연결점 두 번 클릭만 처리하고 빈 곳 드래그를 처리하지 않음 | 드래그와 시작·끝 두 번 클릭을 같은 생성 경로에 연결 |
| Pwh 공통 편집기 | 도형 생성의 실행 취소 누락, 그리기 모드 중복, 숨겨진 도구를 기준으로 메뉴 위치 계산 | 스냅샷 명령·단일 그리기 상태·현재 보이는 버튼을 사용 |
| rhwp 기반 코어 | 링크 종류의 기본 화살표가 명시적인 화살표 종류·크기를 덮어씀 | 조회·변경·화면·저장에 같은 기본값 규칙 적용 |
| rhwp 기반 코어 | 셀 도형의 위치 목록이 중첩 경로를 한 단계로 축약 | 조판 트리의 상위 표 소유 경로를 유지하여 선택·속성과 같은 주소 사용 |
| Pwh 공통 편집기 | 단일 쪽 기본 설정으로 화면을 축소해도 세로로만 표시 | 기존 Studio 자동 배치에 기본값과 설정 이전 연결 |

## 지원 범위

- 그리기 개체 8개: 글상자·사각형·타원·직선·호·다각형·곡선·자유선.
- 연결선 9개: 직선·꺾인선·곡선 × 화살표 없음·단방향·양방향.
- 선의 색·굵기·종류·끝 모양과 시작·끝 화살표·크기. 일반 도형·선의 더블클릭은 속성을 열고 글상자는 내용 편집에 진입합니다.
- 다각형·곡선은 꼭짓점을 입력하고 Enter·더블클릭으로 완료합니다. Esc는 미완성 그리기를 취소합니다. 자유선은 입력 점 수를 제한해 무제한 누적을 막습니다.
- 자동 쪽 배치는 화면 폭·배율에 맞춰 열 수를 정하고 왼쪽→오른쪽, 다음 줄 순서로 표시합니다. 쪽 나눔과 저장 치수는 변경하지 않습니다.

이전 버전은 단일 쪽 기본값과 사용자의 명시적 선택을 구분해 저장하지 않았습니다. 표시가 없는 이전 단일 쪽 설정은 처음에 자동으로 이전하며, 이후 명시적으로 고른 배치는 보존합니다. 기존 수평 이동 설정은 이전 대상에서 제외합니다.

## 검증

최종 후보의 검사 결과는 아래 표에 기록합니다. 사용자 원문은 시험 사본으로만 읽고 변경하지 않습니다.

| 검사 | 범위와 결과 |
| --- | --- |
| 공통·Desktop 빌드 | 서로 독립된 두 번의 빌드에서 6개 산출물 일치. 실제 Studio TypeScript 309개와 Pwh 어댑터 19개를 strict 검사 |
| 실제 입력 | 최종 후보 17개 도구의 마우스 생성·선택·Ctrl+Z·다시 실행 모두 통과. 다각형 Esc 취소와 도형 목록의 상하 방향키 이동 확인 |
| 속성 화면 | 곡선 연결선 더블클릭, 색·굵기·종류·화살표 적용, Ctrl+Z와 다시 실행의 속성 일치 |
| 코어 회귀 | 전체 682개 통과·실패 0·환경/자료 조건으로 40개 건너뜀. 이 중 도형 관련 29개는 17개 생성·HWP/HWPX 재열기, 연결점 추종·복원, 선 속성 3종, 일반·중첩 셀 삽입과 원문 소유 경로를 검사 |
| 중첩 글상자 실제 입력 | 2단계 셀 안에 생성한 글상자를 전체 경로로 다시 선택. 더블클릭 후 3단계 경로로 글 입력, Ctrl+Z 두 번으로 내용·생성 전 상태 복원 |
| 쪽 배치 | 35%에서 편집 영역 폭 400 / 700 / 1000 / 1500에 따라 1 / 2 / 3 / 5열. 줄 전환 순서, 두 번째 쪽과 다음 줄 넷째 쪽 본문 클릭 주소 확인. 배치·배율 변경 전후의 문서 글자 좌표 불변 |
| 기존 조판 보존 | 같은 글꼴 환경에서 7개 문서 256쪽의 전체 글자 좌표·인쇄 SVG 일치. 기존 150쪽 묶음·17쪽 문서를 포함하고, 동일한 78쪽 사본은 중복 집계에서 제외 |
| 정적 검사와 배포 입력 | JavaScript lint 434개, 오류·경고 0. 공통·Desktop의 소스 입력·번들 해시 및 Desktop 공개 소스 manifest 검사 통과 |

코어는 고정 rhwp 0.8.7 원본에 기존 97개와 새 98번을 순서대로 적용해 Rust 1.93.1 / wasm-bindgen 0.2.127로 빌드했습니다. 앞선 97개 패치의 순서·내용·해시는 변경하지 않았습니다.

```text
98번 패치 SHA-256: 1ddd297bd3a094289bc91bca8c56cda25d1ace2b9d163f49a7e0d945909a92aa
후보 WASM SHA-256: 9947cb9592d4445b0516d746250a5b73bfd2987c724e209113a3552303ac63fe
```

일반 재현 명령은 `node scripts/verify-editor-build.mjs --typecheck`, `node tools/quality/run.mjs lint`, `node desktop/verify-source.mjs`입니다. 코어 검사는 `PWH_RUNTIME_ROOT`를 후보 런타임, `PWH_ENGINE_SOURCE`를 패치한 소스로 지정하고 `node scripts/run-ci-tests.mjs core`를 실행합니다. 생략된 코어 경로나 건너뛴 검사는 후보의 통과로 집계하지 않습니다.

## 남은 제한

- 선 투명도·선 굵기 내부 적용, 호·부채꼴 종류 변경은 지원하지 않으며 해당 설정은 비활성화합니다. 사각형 모서리는 사각형 모델에서만 활성화합니다.
- 셀 안 연결선은 자유 배치로 생성할 수 있습니다. 개체 연결점에 붙여 추종하는 동작은 본문 개체를 대상으로 검증합니다.
- 세로 글상자, 모든 고급 도형·연결점 편집, 모든 그룹 내부 편집을 지원한다는 뜻은 아닙니다.
- 기존 조판 보존 검사는 한컴 PDF와의 새로운 일치율 검사가 아닙니다. 한컴 출력과의 차이는 별도의 PDF 비교에서 판정합니다.
