# Linux Desktop 검증 범위

기준은 Pwh 0.6.63, Desktop 0.1.44, 공통 WASM r32입니다. Linux x64 시험 환경은 Ubuntu 26.04 LTS·WSL2·WSLg입니다. 네이티브 설치와 다른 배포판의 검증을 대신하지 않습니다.

## 공통 조판

Windows와 Linux에서 동일한 WASM과 편집기 번들의 SHA-256을 확인했습니다. 동일한 코어·기본 글꼴 측정 조건에서 8개 문서·538쪽의 쪽 수, 쪽별 글자 배치 JSON과 인쇄 SVG를 비교했으며 모두 일치했습니다. 기존 150쪽 묶음, 17쪽 표 문서, 4쪽 셀 조절 문서와 282쪽 문서를 포함합니다. 원본 문서는 수정하지 않았습니다.

이 비교는 운영체제별 코어 계산의 차이를 확인합니다. 한컴 출력과 538쪽 전체가 일치한다는 뜻은 아닙니다. 설치 글꼴이 다른 일반 사용 환경의 차이는 엔진 오류와 구분합니다.

## 앱과 저장

- 실제 Linux Electron 창과 인증된 Unix 소켓의 시작·정상 종료.
- 실제 편집기에서 4쪽 문서 사본 로드·문자 입력·Ctrl+Z·Ctrl+Shift+Z·Ctrl+S·보기 메뉴 선택.
- 저장 후 dirty 해제, HWPX 재열기와 입력한 내용·4쪽 유지.
- Windows와 Ubuntu의 업데이트 자산 선택·다운로드 해시·저장·Store 채널 분리·Linux 설치 경로 검사.
- 공개 소스 manifest, 공통 편집기 빌드 입력과 정적 검사.

## 패키지 업데이트

전체 Linux 패키지로 격리된 사용자 설치의 0.1.43→0.1.44 전환을 시험했습니다. 현재 버전 링크 전환, 새 WASM 해시, 사용자 문서 보존과 재실행 경로 호출을 확인했습니다.

손상된 패키지는 설치하지 않고 기존 버전의 재시작 경로로 복귀합니다. 앱이 계속 실행 중이면 강제로 종료하거나 교체하지 않습니다. 아카이브의 링크·특수 파일은 추출 전에 거절합니다. GitHub 업로드 후의 실제 업데이트 조회와 일반 사용자의 장시간 실행은 별도 확인 대상입니다.

## AI와 운영체제 경계

격리된 D-Bus Secret Service에서 계정 자료의 암호화 저장·재읽기와 평문 비포함을 확인했습니다. 공식 고정 Linux AI 패키지의 파일별 해시와 app-server 초기화 응답을 확인했습니다. 실제 ChatGPT 계정 로그인·유료 모델 요청, 별도 설치된 Codex CLI와 플러그인 연결은 이 검사에 포함하지 않습니다.

실물 프린터, Linux 한글 입력기의 조합 입력, 여러 모니터·배율·그래픽 드라이버와 다른 데스크톱 환경은 추가 검증이 필요합니다. 미검증 경로를 검증 완료로 표시하지 않습니다.
