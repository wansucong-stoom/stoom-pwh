# 탭별 그래픽 메뉴 검증

이 변경은 **Pwh 공통 편집기**의 rhwp Studio 유래 메뉴·도구 상자·명령 상태 연결에 적용합니다. Desktop 호스트는 최소 창 너비를 360으로 조정합니다. 공통 WASM 코어 r29, 글줄·표 높이·쪽 분할 알고리즘은 유지합니다. 아직 정식 릴리스에 포함되지 않은 개발 소스 기준입니다.

## 확인한 동작

| 범위 | 결과 |
| --- | --- |
| 일곱 메뉴 전환 | 선택한 패널 하나만 표시하고 79 CSS px 높이 및 하단 서식 줄 유지 |
| 본문 서식 | 선택한 글을 유지한 채 탭 전환·진하게 적용, 실행 취소 후 원문과 서식 복원 |
| 실제 대화상자 | 글자 모양·문단 모양·편집 용지·필드 입력·문자표 열림 |
| 키보드 실행 | Enter로 문자표가 한 번 열림 |
| 표 상태 | 본문에서 표 속성 비활성, 셀 안에서 활성화 및 대화상자 열림 |
| F5 셀 블록 | 상태 알림으로 너비·높이 같게 버튼 갱신, 너비 적용 및 실행 취소 확인 |
| 치수 보존 | 서로 다른 두 열 21,577 / 20,377 HU → 20,977 / 20,977 HU, 실행 취소로 원래 값 복원 |
| 좁은 폭 | 편집기 360 CSS px에서 페이지 전체 가로 넘침 없이 메뉴 한 줄 유지, » 메뉴의 End·Enter 선택 및 도구 그룹 이동 |
| 스타일 | 문서의 실제 스타일 선택과 실행 취소에 선택 표시가 동기화됨 |
| 머리말 편집 | 일반 패널을 숨기고 전용 도구 표시, 닫으면 직전 패널 하나만 복원 |
| 어두운 테마 | 기존 테마 색상 토큰을 따라 글자·아이콘·배경 대비 유지 |

시험에는 합성 문서만 사용했습니다. 사용자 원본이나 설치판은 변경하지 않았습니다. 한글의 화면 이미지·아이콘 자산은 포함하지 않습니다.

## 빌드와 회귀 검사

- 공통 편집기와 Desktop 번들을 독립된 두 디렉터리에서 각각 빌드하고 여섯 산출물의 바이트 일치를 확인했습니다.
- Studio TypeScript 소스 303개에 strict/noEmit 검사를 통과했습니다. 새 컨트롤러·아이콘도 검사 대상에 포함합니다.
- 메뉴 모형·빌드 입력 계약·시험 자동 발견 검사 9건을 통과했습니다. 변경한 JavaScript의 정적 검사와 번들 입력·manifest·공개 소스 SHA-256 검사를 통과했습니다.
- 기존 Node 회귀 시험은 로컬 서버 접근이 허용된 환경에서 종료 코드 0을 확인했습니다. 브라우저·별도 코어 경로가 필요한 선택 시험의 생략은 통과로 계산하지 않습니다.
- CI용 실제 메뉴·표 선택·개체 속성 회귀 시험을 현재 패널 선택 방식에 맞췄습니다. 위 실제 화면 검증과 CI 전체 브라우저 잡 실행은 구분합니다.

## 제한

모든 한글 기능을 새로 구현한 변경은 아닙니다. 문단 띠·메모 등 미구현 명령은 그래픽 패널에 넣지 않으며, 기존 명령의 병합 셀·양식 모드·읽기 전용 제한을 유지합니다. 이번 변경에서 기존 대규모 조판 문서의 PDF 일치도를 새로 측정하지 않았습니다.
