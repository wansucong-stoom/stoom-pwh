# 탭별 그래픽 메뉴 검증

이 변경은 **Pwh 공통 편집기**의 rhwp Studio 유래 메뉴·도구 상자·명령 상태 연결에 적용합니다. Desktop 호스트는 최소 창 너비를 360으로 조정합니다. 공통 WASM 코어 r29, 글줄·표 높이·쪽 분할 알고리즘은 유지합니다. 아직 정식 릴리스에 포함되지 않은 개발 소스 기준입니다.

시험에는 합성 문서만 사용했습니다. 사용자 원본이나 설치판은 변경하지 않았습니다. 한글의 화면 이미지·아이콘 자산은 포함하지 않습니다.

## 빌드와 회귀 검사

- 공통 편집기와 Desktop 번들을 독립된 두 디렉터리에서 각각 빌드하고 여섯 산출물의 바이트 일치를 확인했습니다.
- Studio TypeScript 소스 306개에 strict/noEmit 검사를 통과했습니다. 새 컨트롤러·아이콘·갤러리·모양 복사 창도 검사 대상에 포함합니다.
- 메뉴 모형·빌드 입력 계약·시험 자동 발견 검사 9건을 통과했습니다. 변경한 JavaScript의 정적 검사와 번들 입력·manifest·공개 소스 SHA-256 검사를 통과했습니다.
- 최종 Node 회귀 시험은 **280개 통과·0개 실패·386개 생략**입니다. 이번 선택·모양 복사·제어부호·네이티브 붙이기·빌드 계약 관련 격리 시험 18개를 포함합니다. 브라우저·별도 코어 경로가 필요한 선택 시험의 생략은 통과로 계산하지 않습니다.
- CI용 실제 메뉴·표 선택·개체 속성 회귀 시험을 현재 패널 선택 방식에 맞췄습니다. 위 실제 화면 검증과 CI 전체 브라우저 잡 실행은 구분합니다.

## Desktop 붙이기 검증

기존 버튼은 `execCommand('paste')`의 실패를 별도로 처리하지 않았습니다. 새 Desktop 연결은 앱 소유 최상위 IPC·활성 편집 프레임·문서 epoch와 변경 번호·커서·선택·textarea 포커스를 확인한 뒤 네이티브 편집 명령을 실행합니다. 편집 iframe에 명시한 `name="editor"`와 실제 Electron 프레임 이름을 일치시킵니다. 공통 편집기의 기존 paste interceptor와 지원 MIME 처리는 그대로 사용합니다.

별도 Desktop 시험 창에서 상단 버튼의 요청이 **isTrusted=true인 paste 이벤트**, 실제 입력창 포커스까지 도달하는 것을 확인했습니다. 이 검사는 이벤트를 소비하고 클립보드 내용은 읽지 않습니다. 지연 중 포커스 이동·조회 거절·중복 요청·실패 후 재시도는 격리 시험으로 확인했습니다. 실제 내용의 교체, HTML·RTF·그림·내부 토큰 조합과 실행 취소의 전체 통합 시험을 완료했다는 뜻은 아닙니다. 임시 클립보드를 사용하는 자동 입력 시험은 Windows 클립보드 접근 오류로 실행하지 못했으며, Pwh의 재현된 실패로 계산하지 않습니다.

## 제한

모든 한글 기능을 새로 구현한 변경은 아닙니다. 문단 띠·메모 등 미구현 명령은 그래픽 패널에 넣지 않으며, 기존 명령의 병합 셀·양식 모드·읽기 전용 제한을 유지합니다. 이번 변경에서 기존 대규모 조판 문서의 PDF 일치도를 새로 측정하지 않았습니다.

모양 복사의 셀 속성은 일반 표의 F5 셀 블록에 적용합니다. 중첩 셀 모양·스타일 복사·셀 치수 복사는 제외합니다. 표시 제어부호 삭제는 본문의 감추기와 Delete 앞 경계만 지원하며, 모든 부호의 Backspace·선택 삭제를 일반화한 변경은 아닙니다. 코어 r29의 바이트와 조판 계산은 변경하지 않습니다.
