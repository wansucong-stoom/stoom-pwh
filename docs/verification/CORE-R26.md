# 공통 코어 r26 조판 검증

r26은 rhwp 기반 공통 코어의 기호 문자 폭과 표 연속 조각의 높이 보존을 보완합니다. 문서나 쪽을 지정한 실행 조건은 추가하지 않습니다. Pwh 공통 편집기와 Desktop이 같은 코어를 사용합니다.

## TEST 4 · 78쪽 비교

한컴 기준 PDF와 Pwh의 인쇄 미리보기 PDF를 물리 쪽 번호 그대로 대조했습니다. 150dpi, 2픽셀 허용 거리, 명도 임계값 245(일반)·180(진한)을 고정하고 원점 이동·크기 맞춤·쪽 재배열을 하지 않았습니다. 쪽별 기준은 일반 F1 95% 이상이면서 진한 F1 90% 이상입니다.

| 대상 | r25 일반 / 진한 F1 | r26 일반 / 진한 F1 |
| --- | ---: | ---: |
| 전체 잉크 가중 | 99.17% / 98.54% | 99.67% / 99.32% |
| 물리 13쪽 | 89.02% / 83.31% | 98.26% / 97.33% |
| 물리 19쪽 | 64.75% / 54.33% | 99.99% / 99.97% |
| 쪽별 수치 기준 통과 | 76 / 78쪽 | 78 / 78쪽 |

13쪽의 기호 접두 런은 전체 폭과 문자 누적 좌표의 끝이 달라 다음 서식 런을 밀었습니다. 원본 기호 코드를 폭 측정 때 유지하여 합성기·커서·다음 런의 시작을 맞춥니다. 19쪽은 첫 표 조각이 실제 공간을 넘는 글줄까지 채택하고, 이어지는 조각의 남은 행 최소 높이를 잃었던 문제입니다. 내용 예산과 물리 프레임의 소유 높이를 함께 보존합니다.

## 기존 TEST 문서 4개 · 167쪽

46·65·39·17쪽의 쪽 수를 유지하고 저장·재열기에서 각 코어의 글자 좌표·인쇄 SVG가 유지되는지 확인했습니다. 167쪽 중 162쪽은 r25와 글자 좌표와 인쇄 SVG가 같습니다. 달라진 5쪽은 기호 문자 폭 수정의 영향이며, 별도의 한컴 PDF 비교에서도 같은 기준을 충족합니다.

| 익명 문서 | 달라진 물리 쪽 | r26 일반 / 진한 F1 |
| --- | --- | ---: |
| TEST A · 46쪽 | 13 | 97.84% / 96.08% |
| TEST B · 65쪽 | 18 | 98.68% / 97.68% |
| TEST B · 65쪽 | 39 | 99.69% / 99.40% |
| TEST C · 39쪽 | 8 | 97.44% / 93.45% |
| TEST D · 17쪽 | 3 | 99.23% / 98.68% |

표 내용 예산 수정은 위 167쪽에서 기호 폭 수정 결과를 추가로 바꾸지 않았습니다. 결과 유지와 한컴 대비 새 비교를 구분하며, 기존 문서 전체의 한컴 PDF 점수를 새로 측정했다는 뜻은 아닙니다.

## 시험과 한계

- [기호 문자 폭](../../tests/legacy-symbol-run-advance.test.mjs): 세 종류의 레거시 기호, 보통 문자, 유니코드 기호, 혼합 서식, 기존 전용 문자 변환을 검사합니다.
- [표 연속 배치 보존](../../tests/stored-frame-visible-content-fit.test.mjs): 이미 정상인 표의 앞쪽 글줄과 이어지는 글줄을 보존하는 대조 시험입니다. 이 합성 문서만으로 발견 결함의 재현을 주장하지 않습니다.
- [원본 프레임 증명 함수](../../tests/stored-label-frame-source.test.mjs): 실제 Rust 함수를 추출해 원본 프레임의 닫힘, 간격 포함·제외, 평행 셀, 병합, 편집·개체와 잘못된 치수를 검사합니다.
- 전체 코어 회귀 시험과 별도로 실제 Pwh 인쇄 미리보기 메뉴에서 문서를 출력하고 PDF를 검사했습니다. ego-lite Chromium의 PDF 출력이며 설치된 Electron의 네이티브 프린터 대화상자 검증과는 구분합니다.
- F1은 허용 거리 안에서 잉크가 겹치는 지표입니다. 문서 의미·글자 내용·편집 정확도의 백분율이 아니며, 78쪽의 모든 글자를 개별 인증했다는 뜻이 아닙니다. 글꼴의 세부 자폭·획 차이는 남습니다.
- 원본 문서는 변경하지 않았습니다. 사용자 문서·PDF·조판 분석 JSON·개인 경로는 공개 저장소와 배포물에 포함하지 않습니다.
