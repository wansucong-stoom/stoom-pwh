# 표 자동 채우기

[사용 안내](USER-GUIDE.md) · [표 안의 명령](TABLE-COMMANDS.md) · [변경 이력](CHANGELOG.md)

다음 배포를 위한 개발 소스에 포함된 기능입니다. 정식 0.6.60 / Desktop 0.1.41 설치판에는 아직 포함되지 않습니다.

## 숫자나 문자열을 이어 채우기

1. 같은 줄이나 칸에 `1, 2, 3`처럼 기준 값을 입력합니다.
2. **기준 값이 있는 셀과 채울 빈 셀을 함께** 드래그합니다. 키보드로는 첫 셀에서 **F5 두 번**을 누른 뒤 방향키로 범위를 넓힙니다.
3. 우클릭의 **표 자동 채우기** 또는 셀 블록 단축키 **A**를 실행합니다.

**선택한 범위 안의 빈 셀만 채웁니다.** 기존 값과 선택 밖의 셀은 그대로 둡니다. 기준 셀만 선택했으면 바뀌는 내용이 없습니다. 예를 들어 세로로 `1, 2, 3, 빈 셀, 빈 셀`을 선택하면 마지막 두 셀에만 `4, 5`가 들어갑니다.

방향은 드래그의 시작·끝 셀에서 정합니다. 세로로 선택하면 상하로, 가로로 선택하면 좌우로 읽고 채웁니다. 위쪽이나 왼쪽으로 드래그한 경우도 그 방향을 따릅니다. 별도의 방향·범위 설정은 없습니다.

| 기준 값 | 이어지는 내용 |
| --- | --- |
| `1, 2, 3` | `4, 5, 6…` |
| `2, 4, 6` | `8, 10, 12…` |
| `0.1, 0.2` | `0.3, 0.4…` |
| `001, 002` | `003, 004…` |
| `제1호, 제2호` | `제3호, 제4호…` |
| `11월, 12월` | `1월, 2월…` |
| `토요일, 일요일` | `월요일, 화요일…` |
| 등록된 규칙이 없는 문자열 | 입력한 순서를 반복 |

기준 숫자가 하나이면 같은 값을 반복합니다. 일정한 증감은 두 개 이상의 연속된 기준 값으로 지정하세요. 여러 줄·칸을 포함한 직사각형 선택은 선택한 축을 따라 다음 줄·칸으로 이어갑니다.

## 기본 목록과 사용자 정의 목록

**자동 채우기 내용…**에서 기본 목록을 고르면 선택 범위의 빈 셀을 목록 첫 항목부터 채웁니다. 기존 값은 유지합니다. 한글·영문·한자 월과 요일, 가나다·알파벳, 숫자·서수, 천간·지지·육십갑자·24절기 등의 목록을 제공합니다. 목록 끝에서는 처음으로 돌아갑니다.

**사용자 정의**에서 이름과 쉼표 또는 줄바꿈으로 구분한 항목을 입력하고 **추가**를 누릅니다. 저장한 목록은 다음 실행에서도 사용할 수 있고 자동 규칙 인식에도 사용됩니다. **삭제**는 선택한 사용자 목록만 지웁니다. 목록은 이 PC의 Pwh 설정에 저장되며 문서 본문이나 외부 서버로 전송되지 않습니다.

## 서식과 실행 취소

일반 표와 중첩 표 모두 해당 표의 셀 경로로 처리합니다. 대상 셀의 테두리·배경·문단 속성과 첫 글자의 글자 모양을 유지하며, 셀 내용만 바꿉니다. **Ctrl+Z 한 번**으로 전체 채우기를 되돌리고 **Ctrl+Shift+Z**로 다시 실행합니다. 바깥 표나 이웃 셀은 채우기 대상으로 바꾸지 않습니다.

현재는 같은 크기의 연속된 셀과 한 문단의 평문을 지원합니다. 선택에서 제외한 셀, 병합 셀, 여러 문단·개체·제어 문자가 포함된 셀은 변경 전에 거절합니다. 원본 셀의 복합 서식을 목적 셀에 복제하는 기능은 아닙니다.

## 구현과 검증 범위

rhwp Studio 유래 Pwh 공통 편집기에 명령·단축키·대화상자를 추가하며, 기존 r29 코어의 셀 편집·배치·실행 취소 API를 사용합니다. 조판 알고리즘이나 쪽 나눔 규칙은 변경하지 않습니다. 공통 편집기와 Desktop 번들을 같은 소스로 생성합니다.

- [규칙 검사](../tests/auto-fill.test.mjs): 드래그의 상하좌우 방향, 선택 밖·기존 값 보존, 기준 셀만 선택한 경우, 숫자 정밀도·앞자리 0·접두사, 월·요일 순환과 병합 거절.
- [실제 코어 검사](../tests/auto-fill-wasm.test.mjs): 네 방향, 대상 셀 속성 보존, 중첩 표·이웃 불변, 스냅샷 복원과 HWPX 저장·재열기.
- [사용자 목록 저장 검사](../tests/auto-fill-preferences.test.mjs): 재열기, 동시 요청, 삭제와 잘못된 요청·용량 초과 시 기존 목록 보존.
- [화면 회귀 검사](../tests/auto-fill-browser.test.mjs): 셀 블록 A, 한 번의 실행 취소·다시 실행, 대화상자 Tab·Shift+Tab·Space·Enter와 선택 변경 시 취소.

검증은 합성 문서와 고정된 r29 코어를 기준으로 합니다. 모든 사용자 문서와 설치된 Electron·Windows IME 조합의 동작을 보장하는 범위는 아닙니다.
