# 쪽별 조판 검증 기준

Pwh의 조판 개선은 한글에서 출력한 기준 PDF와 같은 원본 문서의 Pwh 출력 PDF를 비교한다. 앞쪽 쪽 나눔의 차이가 뒤쪽까지 전파되므로 **1쪽부터 연속으로 통과한 구간**을 관리한다. 전체 평균이 높아졌다는 이유로 앞쪽의 미해결 차이를 건너뛰지 않는다.

## 통과 조건

각 물리 쪽에 다음 조건을 함께 적용한다.

| 구분 | 고정 기준 |
| --- | --- |
| 비교 위치 | 같은 쪽 번호, 같은 용지 원점과 물리 크기 |
| 래스터화 | 150 dpi, 흰색 배경 |
| 일반 잉크 | 임계값 245, 2픽셀 허용 F1 **0.95 이상** |
| 진한 잉크 | 임계값 180, 2픽셀 허용 F1 **0.90 이상** |
| 내용 | 원문 누락과 중복 없음. PDF 내부 그리기 순서 차이는 별도 대조 |
| 영역 | 본문·표·그림의 실제 넘침 없음. 테두리·여백·쪽번호의 소유 쪽 확인 |
| 이전 구간 | 이미 통과한 앞쪽 구간이 새 출력에서도 모두 통과 |

F1은 지정한 허용 거리 안의 잉크 위치를 비교한 지표이며, “문서 전체가 그 비율만큼 동일하다”는 뜻이 아니다. 숫자가 기준을 넘더라도 테두리 높이나 쪽번호가 잘못됐으면 통과로 인정하지 않는다. 비교를 위해 쪽을 재배열하거나 이미지를 이동·확대·축소해 오차를 숨기지 않는다. 기준을 낮춰 다음 쪽으로 넘어가지 않는다.

## 실행 흐름

1. 원본, 한글 기준 PDF, Pwh 출력 PDF의 SHA-256을 기록한다. 실문서는 시험 사본만 사용하며 저장소에 넣지 않는다.
2. `scripts/compare-pages.py`로 **모든 물리 쪽**을 각각 일반 잉크와 진한 잉크 조건에서 비교한다. 진단용 일부 쪽 출력은 전체 검증 자료로 사용할 수 없다.
3. 현재 검토 중인 쪽의 텍스트, 조판부호와 개체의 배치 근거, 경계 넘침을 확인한다. 확인하지 않은 검사는 명시적으로 미검증 상태로 남긴다.
4. 보고서 바이트와 문서 해시에 묶인 감사 자료를 `scripts/check-layout-gates.mjs`에 전달한다. 수정 전 승인 기록이 있으면 `--previous`로 전달하여 앞쪽 구간도 다시 검증한다.
5. 처음 미통과한 쪽을 개선한다. 그 쪽이 통과하면 다음 쪽으로 이동한다. 새 엔진 출력마다 이전 승인 구간을 다시 검사한다.

```text
node scripts/check-layout-gates.mjs --normal NORMAL.json --dark DARK.json --audit AUDIT.json --previous PREVIOUS.json --output NEW-GATE.json
```

첫 실행에는 `--previous`를 생략한다. 출력 파일은 기존 검증 기록을 덮어쓰지 않는다. 종료 코드는 전체 통과 `0`, 미통과 구간 존재 `1`, 자료·해시·조건 오류 `2`이다. `acceptedThrough`는 연속 승인한 마지막 쪽, `currentPage`는 다음에 해결할 첫 쪽이다. 뒤쪽 쪽이 우연히 점수 기준을 넘더라도 앞쪽이 미통과하면 `not-reached`로 남는다.

감사 자료의 형식은 도구의 `--help`에 명시돼 있다. 자료가 없거나 원본·출력·보고서 해시가 다르면 승인할 수 없다. 이전에 승인한 구간이 깨지면 `previous-prefix-regression`으로 표시한다. 해시는 자료 연결을 검증하며, 사람이 확인하지 않은 내용을 자동으로 검증했다고 증명하지는 않는다.

## 수정과 배포의 경계

차이의 원인은 rhwp 원천 코어, rhwp Studio에서 유래한 Pwh 공통 편집기, Pwh Desktop 호스트로 구분해 기록한다. 코어 수정은 원본을 꾸미거나 잘라내는 보정 대신 문서의 여백·높이·줄 정보·개체 소유 관계가 조판에 적용되는 규칙을 수정한다. 단일 문서에서 개선됐다는 결과만으로 전체 문서의 일치도를 보장하지 않는다.

쪽별 진척 자료는 해당 시험 문서에 한정된다. 엔진을 배포하기 전에는 합성 문서의 음성 사례와 다른 문서의 회귀 검사, Pwh와 Pwh Desktop의 공통 런타임·번들 검증을 함께 수행한다. 실문서, 기준 PDF와 비교 이미지는 공개 저장소·릴리스에 포함하지 않는다.
