# 표 안의 명령과 지원 범위

[문서 모음](README.md) · [한글 호환 단축키](../README.md#한글-호환-단축키) · [발생 계층과 공통 코어](RHWP-DIFFERENCES.md#cell-command-paths)

Pwh 0.6.54 / Desktop 소스 0.1.35 / 공통 코어 r27 기준입니다. Store 앱 반영은 별도 정기 제출 후 이루어집니다.

## 셀과 중첩 표에서 지원

| 작업 | 입력·메뉴 | 처리 기준 |
| --- | --- | --- |
| 셀 안 표 만들기 | `Ctrl+N,T` 또는 표 만들기 | 커서가 속한 셀 문단에 새 표 삽입. 여러 셀이 선택됐으면 먼저 한 셀 지정 |
| 행·열 추가/삭제 | 표 메뉴, `Ctrl+Enter`, `Ctrl+Backspace` | 해당 깊이의 표만 변경. 마지막 행/열은 유지 |
| 셀 병합/분할 | F5 셀 선택 후 `M` / `S` | 대상 표 경로와 선택 범위를 함께 전달 |
| 각 셀 테두리·배경 | F5 후 `L` / `C` | 원래 셀 스타일과 이웃 선을 해당 표 안에서 처리 |
| 선택 영역 테두리·배경 | 표 메뉴의 한꺼번에 적용 | 연속한 셀 범위의 영역 스타일을 해당 표에 적용 |
| 천 단위 쉼표·소수 자리 | 표 메뉴 | 현재 안쪽 셀 문단의 숫자만 변환 |
| 선택 셀 내용 지우기 | Delete, `Ctrl+E` 또는 편집 → 지우기 | 같은 확인 창과 실행 취소 경로 사용 |
| 셀 폭·높이 균등 / 크기 변경 | F5 후 `W` / `H`, Ctrl+방향키 | 기존 경로 기반 조절 유지 |

복사 메뉴도 F5 셀 선택을 인식합니다. 중첩 표 전체 복사는 지원하지만 일부 셀 복사·셀 범위 덮어쓰기는 아래 제한이 있습니다. 셀을 지우는 것과 표 자체를 삭제하는 것은 별개입니다.

## 남은 제한

| 항목 | 현재 처리 | 필요한 보완 |
| --- | --- | --- |
| 중첩 표 자체 삭제·나누기·붙이기·전치 | 사용 불가 | 전체 경로를 받는 구조·클립보드 API와 개체/커서 복원 |
| 중첩 표 수식·블록 계산 | 사용 불가 | 경로 기반 수식 참조·평가·결과 쓰기 |
| 중첩 표 캡션 편집 | 사용 불가 | 캡션 삽입·조회와 편집 모드 진입까지 전체 경로 연결 |
| 중첩 표 일부 셀 복사·셀 범위 덮어쓰기 | 지원 불가 안내, 원문 보존 | 서식·병합·개체를 보존하는 경로 기반 클립보드 처리 |
| 셀 안 새 수식·각주·미주 삽입 | 사용 불가 | 셀 앵커와 편집 컨텍스트를 지원하는 삽입 API |
| 선택에서 제외된 셀을 포함한 테두리/배경 | 사용 불가 | 연속 범위 대신 실제 선택 집합으로 처리 |

이 제한을 단순히 해제하면 안쪽 표의 셀 번호로 바깥 표를 수정할 수 있습니다. 지원이 없는 명령은 UI와 실행 경로에서 함께 막습니다. 기존 그림·누름틀·서식 편집 경로까지 일괄 차단하는 방식은 사용하지 않습니다.

## 원인과 검증

- **rhwp Studio에서 유래한 Pwh 공통 편집기:** 본문 전용 `canExecute`, 중첩 표의 경로를 버린 조회/변경, F5 셀 선택을 빠뜨린 메뉴 조건과 추가 키 차단이 원인이었습니다. 대화상자가 읽은 표와 스냅샷이 수정하는 표를 같은 경로에 묶었습니다.
- **rhwp 기반 Pwh 공통 코어:** 셀 안 표 생성과 중첩 구조·원래 셀 테두리·영역 스타일의 API를 보완했습니다. 문서·쪽·표 번호로 분기하는 보정은 넣지 않습니다.
- **Pwh Desktop:** 별도 원인 수정은 없습니다. 공통 편집기와 코어를 함께 사용합니다.

합성 코어 시험은 깊이 1~3, 문자 중간/여러 문단 삽입, 명시 치수, 내부 클립보드 유지, 구조 변경과 잘못된 입력, 바깥 표·이웃 불변, 원래 테두리·영역 스타일과 저장·재열기를 검사합니다. 별도 명령 시험은 경로 캡처와 스냅샷 변경, 구조 변경 후 커서 및 숫자 길이 보정을 검사합니다.

ego-lite의 합성 시험 문서에서 실제 `isTrusted=true` 키와 버튼으로 셀 안 표 만들기·안쪽 행 추가/삭제·셀 분할·테두리·F5 선택 지우기와 실행 취소·다시 실행을 확인했습니다. 숫자 표기 변환은 명령 디스패치로 확인했습니다. 커서 설정을 위한 시험 API 호출과 실제 키 입력을 구분합니다. 설치된 Electron에서 모든 지원 조합을 사용자 실문서로 시험했다는 뜻은 아닙니다.

정식 코어 회귀 시험은 **574개 통과, 실패 0개, 선택적 시험 13개 건너뜀**입니다. 건너뛴 시험을 통과 수에 포함하지 않습니다.

익명 TEST A/B/C/D/4의 **46·65·39·17·78쪽, 총 245쪽**은 정식 r27 최적화 빌드에서 쪽 수, 글자 좌표, 인쇄 SVG가 r26과 모두 같았습니다. 저장·재열기도 같습니다. 이전 조판 개선의 유지 확인이며, 새 한컴 PDF 점수나 모든 문서의 조판 동일성을 의미하지 않습니다. 원본 문서·개인 경로·시험 출력은 배포하지 않습니다.
