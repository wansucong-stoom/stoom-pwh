# SVG 글자의 실제 잉크와 잘림 검증

이 보완의 발생 위치는 **검증 도구**입니다. 제품의 조판 코어·공통 편집기·Desktop 호스트를 바꾸는 패치와 구분합니다.

SVG의 `getBBox()`는 실제로 칠한 글자보다 큰 글꼴 상자를 반환할 수 있습니다. 설치된 글꼴과 대체 글꼴에 따라 이 상자가 달라지므로, 상자의 일부가 셀 경계를 넘었다는 이유만으로 글자가 잘렸다고 판정하지 않습니다. 기존 상자 검사는 위치 진단 자료로 유지합니다.

## 실제 잉크 검사

익명 합성 SVG의 각 글자 런을 따로 표시하고, 나머지 글자와 표 선·그림은 진단 화면에서 숨깁니다. 같은 위치·크기에서 원래 클립을 적용한 PNG와 클립을 해제한 PNG를 비교합니다. 스크린샷을 다시 Canvas로 읽어 실제 알파 잉크의 손실과 경계 깊이를 측정합니다. 글자 상자는 진단 영역을 확보하는 용도로만 사용합니다.

- PDF 품질 판정과 같은 **150 dpi · 2픽셀**을 [공통 정책](../scripts/check-layout-gates.mjs)에서 가져옵니다. 기존 F1 목표 0.95·0.90과 허용 오차를 변경하지 않습니다.
- 원문 런 전체가 보이지 않으면 허용 오차 안이어도 실패합니다. 경계에서 2픽셀보다 깊은 잉크 손실도 실패합니다. 허용 범위 안의 작은 잉크 잔차는 개수·최대 깊이를 결과에 남깁니다.
- 부모 셀 클립과 물리 쪽 경계를 함께 검사합니다. 회전된 클립, 지원하지 않는 마스크·필터 등을 발견하면 한계로 보고해 통과시키지 않습니다.
- 진단 여백은 쪽 밖의 잉크를 관찰하기 위한 공간입니다. 원래 SVG의 크기와 상대 위치를 유지하며, 실제 제품 출력이나 한컴 PDF 비교에 이동·맞춤을 적용하지 않습니다.

원래 글꼴과 통제한 Arial 대체 글꼴에서 같은 원문의 첫 프레임·이어지는 프레임 소유권을 확인합니다. 일부 글자를 잘라 놓은 반례와 런 전체를 숨긴 반례를 함께 실행해, 클립을 무시하거나 잘린 글자를 성공으로 처리하는 검사를 방지합니다.

이 검사는 합성 문서의 잉크·원문 소유권 검증입니다. 사용자 문서 전체의 조판 일치 승인과는 별개이며, 실제 PDF는 계속 고정된 쪽별 점수와 내용·기하 감사를 통과해야 합니다.
