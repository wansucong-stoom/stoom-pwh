# 변경 이력

사용에 영향을 주는 주요 변경을 정리합니다. 각 버전의 지원 범위는 당시 기준이며, 현재 사용법과 제한 사항은 [README](../README.md)와 [pwh 스킬](../skills/pwh/SKILL.md)을 참고하세요.

## 0.6.19

- 선택한 셀만 복사하고, 기존 셀 또는 본문에 붙여넣는 기능을 개선했습니다.
- Windows 클립보드에서 한글 표·셀을 가져오는 보조 경로와 가져오기 버튼을 추가했습니다.
- 편집기 상단에 실행 버전을 표시합니다.

## 0.6.18

- 표와 미리보기 그림이 함께 복사된 경우 편집 가능한 표를 우선 가져옵니다.
- 업데이트 후 편집기 화면이 갱신되도록 버전 연결을 개선했습니다.

## 0.6.17

- 기존 표의 여러 셀을 AI로 채우는 기능을 추가했습니다.
- AI가 만든 표를 병합 구조가 있는 한글 표로 삽입할 수 있습니다.

## 0.6.16

- AI 수정 요청을 보낼 때 변경되지 않은 문서가 충돌로 처리되는 문제를 개선했습니다.
- 요청 보내기 버튼과 Ctrl+Enter의 동작을 정리했습니다.

## 0.6.15

- 표 안의 글줄과 표 뒤 간격 처리를 개선했습니다.
- 조판 엔진의 수정 근거와 재빌드 자료를 보존했습니다. [기술 기록](engine-patches/README.md)

## 0.6.14

- 편집기의 내장 그림 표시를 개선했습니다. [기술 기록](embedded-images-2026-10-19.md)

## 0.6.13

- 보존 런타임을 이용한 설치와 오프라인 설치 경로를 마련했습니다. [설치 안내](engine-preservation.md)

## 0.6.7

- 기본 파일 편집기와 별도 Studio 호환 경로의 작업 지침을 정리했습니다.

## 0.6.6

- 구조를 보존할 수 없는 셀 내부 붙여넣기를 적용 전에 차단하도록 개선했습니다.

## 0.6.5

- 줄바꿈된 본문의 선택 영역 표시를 개선했습니다.

## 0.6.4

- 큰 표의 셀 선택과 AI 요청 처리를 개선했습니다.

## 0.6.3
