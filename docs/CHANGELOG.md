# 변경 이력

사용에 영향을 주는 주요 변경을 정리합니다. 각 버전의 지원 범위는 당시 기준이며, 현재 사용법과 제한 사항은 [README](../README.md)와 [pwh 스킬](../skills/pwh/SKILL.md)을 참고하세요.

## 개발 중 · CI 유지보수

- Desktop의 MSI와 같은 검증된 런타임으로 MSIX를 생성하는 경로를 추가합니다. 시험판은 별도 패키지·데이터 폴더를 사용하며, MSIX 채널은 MSI 자동 업데이트를 실행하지 않습니다. [시험판과 Store 제출 준비](MSIX.md)

- 릴리스 자산 공개 전의 다운로드 404를 공개 대기와 구분하고, 공개 후 코어·브라우저·재현 빌드를 실행합니다. 브랜치·태그 중복 실행을 줄였습니다.
- 브라우저 시험과 일반·코어 시험의 실행 범위를 분리했습니다. 기본 발견에서 빠졌던 인라인 그림의 쪽 경계 시험을 자동 실행에 포함하고, 셀 속성 시험의 키를 현재 한글 호환 `P`로 맞췄습니다.
- 공개 파일 누락·크기·해시 오류는 실패로 유지하며, 통과·실패·건너뜀을 분리해 표시합니다. [CI와 릴리스 공개 순서](../CONTRIBUTING.md#ci와-릴리스-공개-순서)

## 0.6.51 · Desktop 0.1.32

## 0.6.49 · Desktop 0.1.30

- Windows 공통 편집기에서 한글과 같은 키로 한 줄 지우기, 줄 뒤 지우기, 보통 글자 모양, 문서 처음·끝 이동을 실행합니다. 다시 실행은 `Ctrl+Shift+Z`입니다.
- 표 안의 `Alt+방향키`는 셀 사이를 이동합니다. F5 셀 블록에서는 같은 키로 표 외곽을 유지하며 행·열 경계를 조절합니다. `Shift+Esc`로 현재 표에서 나오고, 최외곽 표에서 `Ctrl+Backspace`로 현재 행을 지웁니다.
- 셀 블록에서 `P`로 표·셀 속성을, `C`로 각 셀의 배경 설정을 엽니다. [지원 키와 문맥](USER-GUIDE.md#한글-호환-단축키)
- Desktop의 `Alt+N`을 파일 메뉴의 새 문서 동작에 연결했습니다. 미저장 변경이 있으면 저장 여부를 확인합니다.

## 0.6.48 · Desktop 0.1.29

- F5 셀 선택 후 키보드로 크기를 조절할 때 문서 모델에서 셀 구조를 읽고, 선택 표시에는 화면에 보이는 쪽의 좌표만 조회합니다. 공통 편집기와 코어를 함께 사용하는 후보에 적용됩니다.

- 셀 블록에서 `W`와 `H`로 열 너비와 행 높이를 균등 배분합니다. `Ctrl+F10`으로 문자표 입력을 열고 원문자·괄호 문자 그룹을 선택할 수 있습니다.
- Desktop에서 새 탭 버튼과 버전 표시를 문서 탭 바로 뒤에 배치합니다. 새 수정본의 기본 이름에는 충돌할 때만 번호를 붙입니다.

- 글줄 폭 측정의 반복적인 글꼴 이름 판별을 줄입니다. 두 시험 문서의 페이지와 글자 좌표가 같은 것을 확인했습니다.
- 더블클릭은 포인터가 가리킨 글자를 기준으로 단어를 선택합니다. 중간 단어 끝을 누를 때 뒤 공백이 선택되던 문제를 보완합니다.

- 공통 코어에서 글자 폭과 위치를 재는 동안 같은 서식의 글꼴 폭 표를 한 번 조회합니다.

- 중첩 표를 키우거나 문단을 나눌 때, 예전 저장 좌표에서 다시 쪽을 넘겨 한 줄만 남던 경우를 공통 조판 코어에서 수정했습니다.

- 셀 폭 변경 뒤 새로 줄바꿈된 문단과 다음 문단이 겹치는 문제를 공통 코어에서 수정했습니다.
- Desktop의 새 탭·닫기·탭 순환과 파일 열기·저장 키를 추가했습니다. 공통 편집기에도 표 행·열 선택, 찾기 겹글쇠, 기존 삽입·서식 명령에 대한 한컴 호환 키를 추가했습니다.
