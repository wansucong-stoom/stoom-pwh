# 변경 이력

사용에 영향을 주는 주요 변경을 정리합니다. 각 버전의 지원 범위는 당시 기준이며, 현재 사용법과 제한 사항은 [README](../README.md)와 [pwh 스킬](../skills/pwh/SKILL.md)을 참고하세요.

## 0.6.30

- 셀 선택 후 C로 셀 속성을, L로 셀 테두리·배경을 열고 선택 영역에 변경을 적용합니다.
- 글자·선·배경 등에 공통 색상표와 최근 사용한 색을 제공하고, 테두리 선의 모양을 미리 보여 줍니다.
- 실제 조판되지 않는 여러 갈래 대각선 선택지를 숨기고 기존 문서의 대각선 정보는 보존합니다.
- Pwh Desktop 0.1.9에서 시작 시 새 릴리스를 확인하고, 사용자가 선택하면 문서 상태와 설치 파일을 확인한 뒤 업데이트합니다.
- Desktop 설치 시 기존 Codex Pwh와 스킬을 같은 버전으로 갱신하거나, 처음 설치하는 PC에 내장된 Pwh를 연결합니다.

## 0.6.29

- 저장된 표의 셀 내용이 커졌을 때 실제 표 높이를 쪽 나눔에 반영해 본문이 페이지 경계 밖으로 넘어가지 않도록 개선했습니다.
- AI 대화창을 접어도 조판기가 화면을 채우도록 수정하고, 대화창 상단에 닫기 버튼을 배치했습니다.
- 수정 후 위치를 차례로 따라가는 자동 표시 효과를 제거했습니다.

## 0.6.28

- AI 텍스트 수정 후 실제 수정 위치로 이동하고 잠시 강조합니다. 직접 조작하면 자동 이동을 멈춥니다.
- Pwh Desktop에서 문서 탭별 편집과 AI 대화를 독립적으로 유지하고, 진행 중인 Codex 작업에 추가 지시를 전달합니다.
- 연결 복구 시 이전 대화를 참고해 현재 문서 상태를 다시 확인하며, 파일 작업과 AI 창 표시를 개선했습니다.

## 0.6.27

- 중첩 표의 페이지별 본문 소유 범위와 부모·자식 표 높이 계산을 보완했습니다.
- 본문·셀·중첩 셀의 문구를 검색해 그 텍스트만 수정합니다. 혼합 서식과 주변 표·그림을 유지하며 여러 수정은 한 번에 되돌릴 수 있습니다.
- Pwh Desktop에 같은 편집 기능과 코어를 연결하고, 공통 소스·빌드 경로를 저장소에 포함했습니다.
- Desktop의 대화·설정 화면과 STOOM 아이콘을 정리하고 Windows 크기별 아이콘의 여백을 보완했습니다.

## 0.6.26

- 한글이나 조판기에서 복사한 표를 셀 안에 편집 가능한 표로 넣을 수 있습니다. 셀보다 큰 표의 가려진 내용과 서식을 유지합니다.
- 표 붙여넣기에서 셀 안에 표로 넣기와 기존 셀에 내용 붙이기를 선택할 수 있습니다.
- 셀 선택 후 내용만 지우거나, 줄·칸 전체를 선택한 경우 해당 줄·칸을 지울 수 있습니다.
- AI가 기존 표 위에 병합 제목 행을 추가하고 셀별 테두리를 변경할 수 있습니다.
- 미저장 복구 안내를 닫는 선택지와 붙여넣기 결과 알림을 추가했습니다.

## 0.6.20

- 한글의 문서 모델이 포함된 복사 내용은 원본 서식과 개체 정보를 활용해 가져옵니다.
- 표의 HTML 서식과 Windows 그림 클립보드 지원을 개선했습니다.

## 0.6.19

- Windows 클립보드에서 한글 표·셀을 가져오는 보조 경로와 가져오기 버튼을 추가했습니다.
- 편집기 상단에 실행 버전을 표시합니다.

- 업데이트 후 편집기 화면이 갱신되도록 버전 연결을 개선했습니다.
