# 변경 이력

사용에 영향을 주는 주요 변경을 정리합니다. 각 버전의 지원 범위는 당시 기준이며, 현재 사용법과 제한 사항은 [README](../README.md)와 [pwh 스킬](../skills/pwh/SKILL.md)을 참고하세요.

## 0.6.37

- 공통·Desktop 번들의 임시 작업 경로를 안정된 모듈 이름으로 정규화하고 두 독립 빌드의 바이트 일치를 검증합니다.
- 빌드 입력 지문을 기록해 소스 변경 후 번들 재생성을 빠뜨린 패키징을 거부합니다.
- CI에서 실제 WASM 전체 시험과 브라우저 시험을 자동 발견해 실행합니다. 합성 문서·별도 프로필을 준비하고 계정·운영체제 연동 시험은 구분합니다.
- MCP stdio의 분할 입력·오류 복구·길이 제한·동시 응답과 네이티브 엔진 실행 실패·종료 코드를 검사합니다.
- 보안 신고 안내와 기여 양식, EditorConfig를 추가했습니다. Desktop 0.1.18과 r10 런타임의 조판 코어는 r9와 같습니다.

## 0.6.36

- rhwp 코어에서 저장된 빈 호스트 표와 다음 문단의 원점을 공유해, 간격의 중복 계산과 추가 쪽 발생을 보완했습니다.
- 내장 기본 글머리표, HWPX 도형의 채움 투명도·윤곽선 구분과 둥근 모서리 비율을 보완했습니다.
- 새 코어와 일치하는 JavaScript 연결부로 Pwh 공통 편집기와 Desktop 0.1.17을 함께 빌드합니다.
- 비교 도구가 같은 물리 배율에서 모든 쪽을 비교하고, 쪽 이미지 폴더·누락/추가 쪽·흰 여백을 제외한 겹침 점수를 다룹니다. 합성 회귀 검사를 CI에 추가했습니다.
- 원본 대비 변경과 전후 비교의 적용 범위·남은 차이는 [조판 일치 검증](LAYOUT-FIDELITY.md)에 정리했습니다.

## 0.6.35

- 공통 편집기에서 표 안의 단어·문단 선택에 정확한 쪽 정보를 전달하고, 글자 수정마다 문서 전체의 글꼴을 다시 조사하던 처리를 제거했습니다.
- 글자를 선택하지 않고 커서만 둔 상태에서도 글자 모양 창이 열립니다. 본문·셀·중첩 셀에서 선택한 글과 다음 입력 글의 서식을 지정할 수 있습니다.
- rhwp 코어에서 본문 각주·미주의 표시 위치, 클릭·커서와 삭제 주소를 맞췄습니다. 문장 중간의 조판부호 위치와 주석 삭제 시 혼합 글자 서식 보존도 보완했습니다.
- 공통 편집기에서 화면의 주석 위치와 본문 글자 오프셋을 구분합니다. 주석 뒤 입력과 바로 옆 글자 수정, 주석 앞뒤 방향키·삭제·실행 취소가 같은 원문 위치를 사용합니다.
- Desktop 0.1.16에서 인쇄 취소·완료 알림을 AI 대화 영역에 표시합니다. 상태 문구 때문에 문서 탭마다 상단 높이가 달라지던 구조를 정리했습니다.
- 오류 발생 계층과 rhwp 원본 대비 변경을 README와 패치 문서에 함께 기록하는 유지관리 기준을 추가했습니다.

## 0.6.34

- 선택한 본문과 셀에 글을 붙일 때 빈 입력으로 원문이 지워지지 않도록 하고, 문단을 포함한 평문 붙여넣기를 한 번에 되돌릴 수 있도록 했습니다. 지연된 표 가져오기 중 문서나 입력 위치가 바뀌면 적용을 취소합니다.
- 문단 안에 떠 있는 표의 배치 위치를 보완하고, 한글과 Pwh의 쪽별 출력을 비교하는 도구를 추가했습니다.
- Desktop에서 문서 탭의 닫기 버튼이 긴 파일명에 가려지지 않도록 하고 AI 대화창의 열림 상태를 열린 문서에 공통으로 적용합니다. 문서별 대화 내용은 따로 유지합니다.
- 대화창을 닫은 상태에서도 문서 상단 오른쪽의 AI 설정 버튼을 사용할 수 있습니다. 설치된 Codex 연결은 비공식 실험 환경임을 표시합니다.
- 선택한 표의 바깥 테두리를 두 번 클릭하면 표 속성을 엽니다. 그림도 두 번 클릭해 속성을 열 수 있습니다.
- Desktop의 인쇄창에서 프린터·매수·쪽 범위·용지·방향을 선택하면서 조판 미리보기를 확인합니다. 모아 찍기·양면·컬러 설정을 제공하며, Alt+P로 엽니다. 그림 저장은 별도 메뉴에서 쪽별로 내보냅니다.
- Desktop은 자체 실행 환경을 포함해 설치된 Edge와 사용자 브라우저 프로필을 사용하지 않습니다. 실행 파일과 작업표시줄에도 승인된 Pwh 제품 아이콘을 적용하고 반복되는 상단 로고를 정리했습니다.
- STOOM 원본 마크의 원형, 대각선 및 은은한 후광을 유지하고 Pwh 제품 표시를 더했습니다.

## 0.6.33

- Pwh Desktop 0.1.14에 새 문서·파일 열기와 최근 문서를 제공하는 시작 화면을 추가했습니다. 열린 문서와 대화는 탭에 유지합니다.
- Pwh Desktop 0.1.14에서 AI 대화창이 좁거나 작업 중일 때 모델·추론 강도 설정창이 잘리지 않도록 수정했습니다.
- 기존 Desktop 0.1.13의 간결한 상단 화면과 같은 계정의 설치된 Codex를 통한 그림 생성·삽입을 유지합니다.

## 0.6.32

- Pwh Desktop 0.1.11에서 OpenAI의 공식 ChatGPT 로그인과 내장 app-server를 통해 문서 작업을 할 수 있습니다. 설치된 Codex 또는 로컬 AI도 선택할 수 있습니다.
- AI 설정에 연결별 상태, 계정 전환과 연결 해제, ChatGPT 사용량 안내를 추가했습니다. 기존 사용자의 AI 연결 선택은 유지합니다.
- 문서별 대화는 인증 갱신 시 이어서 사용하며, Windows 사용자 계정으로 로그인 정보를 암호화합니다.

## 0.6.31

- 본문과 표 셀에서 두 번 클릭으로 단어를, 세 번 클릭으로 해당 문단을 선택합니다. 중첩 표에서도 클릭한 셀 안으로 범위를 제한합니다.
- 저장된 줄 배치가 없는 문서에서 떠 있는 표 뒤에 본문이 겹치지 않도록 쪽 나눔과 조판 높이를 맞췄습니다.
- Pwh Desktop에서 미저장 문서를 닫기 전에 저장·저장하지 않음·취소를 선택할 수 있습니다. 예상치 못한 종료에 대비한 복구본은 유지합니다.
- Desktop에서 HWP·HWPX 파일을 끌어다 놓으면 새 문서 탭으로 열고, 실제 문서 이름과 Desktop·Pwh 버전을 표시합니다.
- 문서 탭을 조판기 위의 파일명 줄로 옮기고 AI 대화창을 접었을 때의 열기 버튼을 정리했습니다. 새 문서의 초기 입력 포커스도 보완했습니다.
- 조판 엔진 변경 설명을 한국어로 정리했습니다.

## 0.6.30

- 셀 선택 후 C로 셀 속성을, L로 셀 테두리·배경을 열고 선택 영역에 변경을 적용합니다.
- 글자·선·배경 등에 공통 색상표와 최근 사용한 색을 제공하고, 테두리 선의 모양을 미리 보여 줍니다.
- 실제 조판되지 않는 여러 갈래 대각선 선택지를 숨기고 기존 문서의 대각선 정보는 보존합니다.
- Pwh Desktop 0.1.9에서 시작 시 새 릴리스를 확인하고, 사용자가 선택하면 문서 상태와 설치 파일을 확인한 뒤 업데이트합니다.
- Desktop 설치 시 기존 Codex Pwh와 스킬을 같은 버전으로 갱신하거나, 처음 설치하는 PC에 내장된 Pwh를 연결합니다.

## 0.6.29

- AI 대화창을 접어도 조판기가 화면을 채우도록 수정하고, 대화창 상단에 닫기 버튼을 배치했습니다.
- 수정 후 위치를 차례로 따라가는 자동 표시 효과를 제거했습니다.

## 0.6.28

- Pwh Desktop에서 문서 탭별 편집과 AI 대화를 독립적으로 유지하고, 진행 중인 Codex 작업에 추가 지시를 전달합니다.
- 연결 복구 시 이전 대화를 참고해 현재 문서 상태를 다시 확인하며, 파일 작업과 AI 창 표시를 개선했습니다.
