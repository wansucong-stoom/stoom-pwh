# 개체 속성 명령의 대상 보존

Pwh 공통 편집기의 **개체 속성** 버튼은 선택한 그림과 표, 또는 커서가 놓인 표의 속성을 엽니다. 그림은 기존 rhwp Studio의 그림 속성 명령을 재사용하며 셀 경로와 머리말·꼬리말 주소를 함께 전달합니다. 일반 본문에서는 버튼을 비활성화합니다.

## 원인과 적용 계층

원인은 **rhwp Studio에서 이어받은 공통 편집기 명령**의 연결에 있습니다. Rust 조판 코어와 Desktop 전용 호스트의 배치 오류가 아닙니다.

- 그림 속성 명령은 상단 버튼 경로에서 셀 경로와 머리말·꼬리말 참조를 빠뜨렸습니다. 우클릭·그림 더블클릭과 같은 기존 그림 속성 명령을 사용하도록 통일합니다.
- 표 개체를 선택해도 문자 커서에 셀 주소가 없으면 상단 버튼 경로가 종료됐습니다. 선택된 표의 주소를 먼저 사용하며, 셀 안의 커서나 셀 블록에서도 해당 표를 엽니다.
- 중첩 표의 속성을 평면 주소로 전달하면 바깥 표를 잘못 선택할 수 있습니다. 현재 코어와 기존 표 속성 창에는 중첩 표의 전체 속성을 조회·설정하는 경로가 없으므로, 지원 안내를 표시하고 바깥 표는 열거나 변경하지 않습니다.

변경은 [공통 명령 연결](../src/pwh-object-properties.ts), [표 대상 판정](../src/object-properties-target.mjs), [빌드 패치](../scripts/patch-object-properties.mjs)에 있습니다. Pwh와 Pwh Desktop을 같은 소스에서 빌드하며 번들과 manifest를 함께 생성합니다.

## 검증 범위

[대상 판정 검사](../tests/object-properties-target.test.mjs)는 선택한 표 주소의 우선권, 셀 커서와 블록의 소유 표, 잘못된 주소의 거절, 중첩 표의 바깥 주소 대체 방지를 확인합니다.

[브라우저 검사](../tests/object-properties-toolbar-browser.test.mjs)는 합성 문서를 사용해 Pwh 공통 호스트와 Desktop 호스트에서 실제 상단 버튼을 클릭합니다. 일반 본문 비활성화, 표 안 커서와 표 개체 선택, 본문 그림·셀 그림·두 단계 중첩 셀 그림의 속성 조회 경로와 닫기 후 상태를 확인합니다. 셀·중첩 셀 그림은 실제 Canvas 클릭으로 선택하며, 본문 그림은 별도의 [마우스·그림 상호작용 검사](../tests/picture-interaction-browser.test.mjs)로도 확인합니다. 중첩 그림의 폭을 변경한 뒤 이웃 그림의 불변과 한 단계 실행 취소를 확인하고, 중첩 표 지원 안내와 바깥 표 불변도 구분해 확인합니다. 실제 Windows 인쇄·계정 연결 시험과 구분되며, 사용자 실문서를 자동으로 수정하지 않습니다.

중첩 표의 전체 속성 편집은 이 수정에 포함되지 않습니다. 셀 안의 그림 속성과 중첩 표 자체의 속성을 같은 지원 범위로 설명하지 않습니다.
