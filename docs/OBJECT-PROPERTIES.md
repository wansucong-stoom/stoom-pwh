# 표와 그림의 개체 속성

Pwh 공통 편집기의 **개체 속성**은 선택한 그림·표 또는 커서가 놓인 표를 엽니다. 중첩 표에서도 해당 표의 전체 셀 경로를 유지합니다. 일반 본문에서는 비활성화합니다.

## 여는 방법

- 표 안에 커서를 두고 상단 **개체 속성**을 누릅니다.
- F5로 셀 블록을 선택한 뒤 **P**를 누릅니다.
- 표 테두리를 더블클릭합니다. 바깥쪽 선택 허용 범위를 넓혀 얇은 선을 정확히 누르는 부담을 줄였습니다.

셀 안의 글자를 더블클릭하면 단어를 선택합니다. 셀 경계에서의 크기 조절과 F5 셀 블록의 키보드 크기 조절을 유지합니다. 겹치는 테두리는 포인터와 가까운 선을 먼저 선택하고 같은 거리이면 더 안쪽 표를 선택합니다.

## 원인과 적용 계층

**rhwp 기반 공통 코어:** 이전에는 중첩 표 전체 속성을 평면 주소로 조회·설정할 수 없었습니다. 표시 좌표에도 원본 셀 경로가 누락됐고 빈 표의 좌표 검색이 글자에 의존했습니다. r25에서 경로 기반 API와 원본 TableNode의 좌표를 제공합니다.

**rhwp Studio에서 유래한 Pwh 공통 편집기:** 선택한 표의 주소를 커서보다 우선하고, 상단 버튼·P·테두리 더블클릭에서 같은 경로를 전달합니다. 속성 창을 열 때 대상을 복사해 두며 바깥 표로 대체하지 않습니다. 바꾸지 않은 속성은 기록하지 않아 치수 반올림과 불필요한 실행 취소 항목을 방지합니다.

**Pwh Desktop 호스트:** 동일한 공통 편집기를 사용합니다. 별도 설치 번들을 직접 고치는 방식으로 처리하지 않습니다.
