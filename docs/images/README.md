# 사용 안내 화면

Pwh Desktop 0.1.42 / 공통 편집기 0.6.61의 실제 화면입니다. 공개 안내용으로 만든 예제 문서를 사용하며 사용자 문서나 계정 정보는 포함하지 않습니다.

- `guide-edit.png`: 편집 탭과 공통 서식 도구 상자.
- `guide-styles.png`: 서식 탭의 문서 전체 스타일 목록.
- `guide-autofill.png`: 표 탭과 선택 범위 안의 연번 자동 채우기 결과.

화면의 메뉴와 기능은 앱에서 직접 실행한 상태입니다. 편집 화면 바깥 영역만 제외했으며 메뉴나 문서 내용의 픽셀을 합성하지 않았습니다. 저장소의 MIT 라이선스로 배포합니다.
