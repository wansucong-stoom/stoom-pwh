# 한글과 Pwh의 쪽 배치 비교

같은 HWP 또는 HWPX 문서를 한컴 한글과 Pwh에서 각각 출력한 결과를 겹쳐서 비교할 수 있습니다. 도구는 원본과 두 출력물을 읽기만 하며, 결과는 새 폴더에 저장합니다.

1. 한글에서 원본을 열고 PDF로 출력합니다. Pwh에서도 같은 원본을 열고 실제 인쇄 경로로 PDF를 출력합니다. 최종 대조는 두 PDF를 같은 렌더러로 이미지화하는 방법을 우선하며, 화면용 쪽 이미지는 보조 진단으로 사용할 수 있습니다.
2. Python 3.11 이상에서 `python -m pip install -r requirements-render-compare.txt`로 검증된 의존성을 준비합니다. 이미지 출력은 `page-0001.png`부터 빠짐없이 번호를 붙인 폴더나 다중 페이지 TIFF로 전달할 수 있습니다. 두 이미지 출력의 해상도는 같아야 합니다.
3. 아직 존재하지 않는 결과 폴더를 지정해 실행합니다.

```powershell
python scripts/compare-pages.py --source "원본.hwpx" --hancom "한글.pdf" --pwh "Pwh.pdf" --dpi 150 --out "비교결과"
```

특정 쪽만 보려면 `--pages 1,3,5-7`을 추가합니다. 각 겹침 이미지에서 빨강은 한글에만 나타난 위치, 파랑은 Pwh에만 나타난 위치, 회색은 일치 위치, 주황은 가까운 차이를 뜻합니다. `report.json`에는 파일 해시, 쪽 수, 설정과 쪽별 차이가 기록됩니다. 두 출력물이 정말 같은 원본에서 생성됐는지는 사용자가 확인해야 합니다.

PDF는 둘 다 같은 `--dpi`로 렌더링합니다. 이미지는 원래 픽셀 크기를 유지합니다. 페이지 원점 이동·크기 맞춤·다른 쪽으로의 대응은 하지 않습니다. 한글 PDF의 용지 반올림은 1포인트 이하인 경우에만 가장자리를 흰색으로 채워 처리합니다. 이미지 폴더의 해시는 순서대로 정렬한 쪽 파일명과 내용으로 계산하며, 글꼴·프로필·기타 진단 파일은 읽지 않습니다.

기본 명도 임계값은 245이고 위치 허용 오차는 2픽셀입니다. `tolerantInkPrecision`은 Pwh의 글자·선·채움 픽셀 중 기준의 허용 범위 안에 있는 비율, `tolerantInkRecall`은 기준 픽셀 중 Pwh의 허용 범위 안에 있는 비율입니다. `tolerantInkF1`은 두 비율의 조화평균입니다. 전체 점수는 쪽별 퍼센트의 단순 평균이 아니라 전체 픽셀 수로 계산합니다. 흰 여백은 점수를 높이지 않으며, 누락·추가 쪽의 잉크는 일치하지 않는 것으로 포함합니다. `exactInkF1`은 위치 허용 오차 없이 계산합니다. 크기 불일치 등으로 비교하지 못한 쪽이 있으면 `aggregate.complete`가 false이므로 전체 일치율로 해석하지 않습니다.

원문 글자나 색상이 같은지, 셀과 문단의 편집 주소가 보존되는지까지 이 점수가 증명하지는 않습니다. 허용 오차를 바꾸면 점수도 바뀌므로 전후에는 동일한 설정을 사용하고, 오차가 큰 쪽의 겹침 이미지와 합성 회귀 검사를 함께 확인합니다. 검증 예와 남은 범위는 [조판 일치 검증](LAYOUT-FIDELITY.md)에 있습니다.

겹침은 글자와 선의 위치를 빠르게 찾기 위한 도구입니다. 글꼴·안티앨리어싱·PDF 출력 방식에 따라서도 색이 나타나며, 수치가 문서의 정확도를 보증하지는 않습니다. 색상이나 편집 가능 여부도 별도로 확인해야 합니다. 원본 문서와 비교 결과에는 개인 정보가 들어갈 수 있으므로 공개 저장소에 올리지 않습니다.
